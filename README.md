# 博客图片压缩

一个单文件的网页小工具，用来把手机照片等大图压到适合放进博客的大小（比如 9 MB 的封面压到 1 MB 以内），并且能直接对比压缩前后的效果。

- 图片只在本机浏览器里处理，不上传、不联网、不需要安装任何东西。
- 支持拖拽、点击选择、Ctrl+V 粘贴截图，可以一次处理多张。

## 怎么用

1. 双击 `index.html`，用 Chrome 或 Edge 打开。
2. 把图片拖进去。
3. 看右边的大小和左边的对比图，满意就点「下载」，得到 `原文件名-min.jpg`。
4. 把下载的图片放进文章文件夹（例如 `content/post/xxx/`），在文章开头写 `image: 文件名`。

## 各项设置是什么意思

| 设置 | 作用 | 建议 |
| --- | --- | --- |
| 输出格式 | JPEG 兼容性最好；WebP 同样画质体积更小 | 不确定就选 JPEG |
| 最长边上限 | 图片的长边超过它就等比缩小 | 封面 1920，正文插图 1280 |
| 画质 | 越高越清晰、越大 | 0.8 左右肉眼基本看不出差别 |
| 目标大小上限 | 压完还超过它，才自动降低画质 | 封面 900 KB，插图 400 KB；填 0 关闭 |
| 画质下限 | 自动降画质的底线，到了底线还超标就改为缩小尺寸 | 0.6，避免压得太糊 |

三个预设按钮（文章封面 / 正文插图 / 高清存档）会一次性填好这些值。设置会记在浏览器里，下次打开还在。

对比图：拖动图片上的分割线，左边是原图，右边是压缩后。想看细节就把「适应窗口」改成「100%」，再滚动查看。

## 工作原理（简单版）

1. 浏览器把图片解码成像素（并按照片里记录的方向自动摆正）。
2. 把像素画到一块 Canvas 画布上，画的时候顺便缩小尺寸。**尺寸减半，像素就只剩四分之一**，这是体积下降的主要原因。
3. 让浏览器把画布重新编码成 JPEG/WebP，画质参数决定丢弃多少肉眼不敏感的细节。
4. 如果设置了目标大小，就用「二分查找」试几次画质：先试中间值，太大就往低试、够小就往高试，几轮后找到"刚好不超标"的最高画质，避免过度压缩。

## 注意

- 输出的图片不含 EXIF 信息（拍摄时间、相机型号、**GPS 位置**等），发到公开博客反而更安全。
- iPhone 的 HEIC 格式浏览器读不了，请先在手机「设置 → 相机 → 格式」里选「兼容性最佳」，或先转成 JPG。
- 如果照片本身画面上印着水印（如相机型号条），那是图像内容的一部分，压缩不会去掉。
